# MultimediaDataProcessing
Low level Coding Exercise of encoding/decoding format, standards and principles.

### ⚠️ Disclaimer

The code within this repository is the result of the learning and study process undertaken for the completion of the Master's degree course **"Multimedia Data Processing"** at **UNIMORE** ([Course Link](https://unimore.coursecatalogue.cineca.it/corsi/2025/10968/insegnamenti/2025/29133/2025/10000?annoOrdinamento=2025&coorte=2025)). 

The primary objective of these exercises was to write code **strictly without the aid of Generative AI tools**, relying solely on official reference documentation. Each task had to be completed within a strict 4-hour time limit, which encompassed reading and understanding the design specifications, followed by manual implementation in C++ using Visual Studio. 

Consequently, due to these strict time and tooling constraints, the code provided in this repository may occasionally appear chaotic, unoptimized, or incomplete. It is shared for educational and archival purposes.
